GitHub Sync — Push CMS to Live Site

Enter your GitHub Personal Access Token so that when you save news, fixtures, standings or videos, the changes are automatically pushed to the live site for all visitors.

Steps to get a token: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → select repo scope.
